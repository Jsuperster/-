# FOC 入门导读与学习路线

> 本文帮助初学者理解“为什么要做这些计算”，然后再阅读已有的 [FOC 电机控制理论笔记](FOC电机控制理论笔记.md)。对象主要是正弦驱动的永磁同步电机（PMSM）；不能把结论直接推广到所有电机。

## 1. 先把控制对象想清楚

永磁转子可以理解为一个会转动的磁铁，定子三相绕组通过电流产生磁场。控制器不是直接给电机一个“速度数字”，而是通过逆变器改变绕组电压，使电流变化，电流与磁场相互作用产生转矩，转矩再改变机械运动。

```text
PWM → 三相平均电压 → 绕组电流 → 电磁转矩 → 加速度 → 转速/位置
                   ↑                     ↑
             电阻、电感、反电动势       负载、摩擦、惯量
```

这里每个箭头都有动态过程。比如转子有惯量，转矩改变后速度不会立即跳到目标值。这也是闭环控制不能只写成“误差乘一个大数”的原因。

单个绕组可用简化方程理解：`v = R i + L di/dt + e`。施加的电压一部分抵消电阻压降，一部分抵消反电动势，剩余部分才用于改变电流。转速升高后反电动势变大，母线电压不变时，电流控制能力会受限制。

## 2. 为什么控制电流，而不是直接控制 PWM

PWM 占空比决定的是桥臂开关的时间比例，并不直接等于电流或转矩。同一个占空比，在不同母线电压、转速和负载下会得到不同电流。

闭环的做法是：测量电流，和期望电流比较，再调整电压指令。这样才能在一定范围内抵抗扰动。PWM 只是把电压指令落到功率器件上的执行手段。

FOC 的特别之处，是选择一个随转子一起旋转的坐标系，把原本来回变化的三相量变成比较容易调节的两个量。

## 3. 三个坐标系：换观察角度，不是换一台电机

### 3.1 abc：从三根相线看

测量 ia、ib、ic。对于没有中性线电流的理想三相系统，`ia + ib + ic = 0`，因此只有两个独立量。实际采样可能有偏置、噪声和开关瞬态，所以三路测量值不一定恰好相加为零。

### 3.2 αβ：站在地面看旋转的矢量

Clarke 变换把三个相关量变成静止平面内的两个分量。采用一组常见的幅值不变约定：

```text
iα = ia
iβ = (ia + 2ib) / √3
```

可以把电流矢量想成平面内的一根箭头。箭头随电机运行旋转，因此两个坐标值仍随时间变化。

### 3.3 dq：坐上跟随转子旋转的观察台

让 d 轴对齐转子永磁磁链，q 轴与之正交。在下面这组约定中：

```text
id =  iα cosθe + iβ sinθe
iq = -iα sinθe + iβ cosθe
```

转子和电流矢量以同样速度旋转时，从这个观察台看，两个分量接近固定值。就像跟着旋转木马转动的人，看旁边座位相对静止。

**算一个小例子：** θe=0，ia=0 A，ib=1.732 A，ic=-1.732 A，则 iα=0 A，iβ≈2 A，得到 id=0 A、iq≈2 A。若只把使用的角度误写为 90°，相同采样值会被算成 id≈2 A、iq≈0 A。可见角度错误会把“想用于转矩的电流”放到错误方向。

不同资料可能采用不同缩放、轴方向和相序。单独复制某个公式到另一套实现，会造成符号或幅值不一致；正变换、反变换、角度、转矩公式必须使用同一约定。

## 4. id 和 iq 各有什么作用

在常见幅值不变 dq 约定下，PMSM 转矩模型为：

`Te = (3/2) p [ψf iq + (Ld - Lq) id iq]`

其中 p 是极对数，ψf 是永磁磁链，Ld/Lq 是两轴电感。具体数值必须与电流、磁链的峰值/有效值及变换约定一致。

- 对表贴式 PMSM，常近似 Ld≈Lq，转矩主要与 iq 成正比；基础控制常设 id*=0。
- 对内嵌式 PMSM，磁阻转矩不可忽略，最优 id 不一定为零，会涉及 MTPA。
- 高速电压不足时可能使用负 id 弱磁，但会增加电流需求并涉及退磁和过压等风险，不是初次调试功能。

假设 p=4、ψf=0.02 Wb、id=0、iq=2 A，采用上述模型且忽略磁阻项，Te≈0.24 N·m。这是模型算例，不是任意电机的电流到转矩换算比例。

## 5. 电角度为什么不是机械角度

`θe = p θm + θoffset`，`ωe = p ωm`。

极对数 p=7 的电机机械转一圈，电角度转七圈。机械转速 600 rpm 对应 10 转/秒，电频率为 70 Hz。

θoffset 表示编码器零位与磁链 d 轴之间的偏置。编码器读数稳定不意味着零位已对齐；角度方向、相序、极对数、传感器延迟同样重要。

没有位置传感器时，可以从电压、电流模型估算角度，但基于反电动势的常见观测方法在零速和很低速度时信号弱，通常需要专门启动策略。不能把“无感”理解成不需要角度。

## 6. 一次电流控制周期发生什么

```text
定时器事件
  → 在可用窗口触发 ADC
  → 获取并校正相电流
  → 读取/估计对应时刻的转子角度
  → Clarke + Park
  → d/q 电流误差送入 PI
  → 电压矢量限幅，必要时抗积分饱和
  → 反 Park
  → SVPWM/SPWM
  → 更新下一周期 PWM
```

关键不是“函数都调用过”，而是这些操作的时间关系正确。ADC 在开关瞬态附近采样，可能得到错误电流；计算结果很晚才更新 PWM，会增加控制延迟。

假设控制周期为 50 μs，即 20 kHz。一次计算和相关处理若占用 35 μs，看似小于周期，但剩余时间仍需覆盖中断响应、DMA、最坏路径以及 PWM 更新截止点。实时性要测最坏情况，不能只看平均耗时。

单电阻、双电阻、三电阻采样的可观测窗口不同。高占空比下采样窗口可能不足，不能只把 ADC 触发固定到“PWM 中点”就认为所有拓扑都正确。

## 7. PI 控制器要注意哪些细节

一种离散位置式示意：

```text
e[k] = target[k] - feedback[k]
u_raw[k] = Kp × e[k] + integral[k]
u[k] = limit(u_raw[k])
integral[k+1] = integral[k] + Ki × Ts × e[k]
```

这是理解用的未完善版本。工程实现还必须加入抗积分饱和等处理：当电压达到上限，积分器继续累计会使退出饱和后恢复很慢，甚至造成大幅超调。条件积分和回算都是常见方法。

- Kp 主要决定误差出现时的即时响应，但过大可能放大噪声并引发振荡。
- Ki 用于消除稳态误差，但过大容易超调、积分累积。
- 改变 Ts 后，若代码中 Ki 已经包含 Ts，就不能再重复乘；不同库的参数定义不同。
- d/q 轴共享可用的电压矢量范围，通常不能把两个轴独立限幅后就不管总幅值。

速度环输出 iq*，电流环输出电压指令。速度环通常比电流环慢，调试时应先保证电流环可靠，再调速度环，最后考虑位置环。

## 8. PWM、电压上限与保护

逆变器的同一桥臂上下管同时导通会导致直通，因此需要互补驱动和死区；但死区也会造成电压误差。SVPWM 能更充分利用直流母线，但不能产生超过母线能力的任意电压。

在常见理想线性 SVPWM 与幅值不变电压矢量定义下，最大相电压基波峰值约为 `Vdc/√3`。这不是线电压有效值，实际还要为死区、器件压降、采样窗口和调制裕量留空间。

FOC 软件闭环不能代替硬件过流保护。应根据系统设计配置驱动器故障检测、比较器/定时器 break、欠压/过压、过温、转速异常以及安全停机路径。

## 9. 推荐实验顺序

1. **不接功率级**：用已知数据验证 Clarke/Park 及反变换，确认单位、角度弧度和符号。
2. **功率级保持关闭**：检查 ADC 零偏、母线电压测量和编码器方向。
3. **按硬件调试规范测试驱动**：核对互补 PWM、死区和硬件关断。测量浮动节点必须使用适合额定电压的差分/隔离测量方案，不能把接地示波器地夹随意夹到相线。
4. **低压、限流、小指令试验**：在安全夹具中确认相序和角度偏置。限流电源也不能替代硬件快速保护；其输出电容仍可能释放大电流。
5. **调电流环**：先小电流，再逐步验证动态；记录 id/iq、指令、电压限幅和故障信息。
6. **调速度环**：限制转矩和加速度，考虑电机停转、编码器掉线等异常。

电机可能突然转动，固定机身并隔离旋转部件。减速时可能回馈能量，使母线升压；普通台式电源通常不能吸收回馈能量，必须在系统设计中考虑制动和过压保护。

## 10. 现象与排查方向

| 现象 | 优先检查 |
|---|---|
| 抖动、无法启动 | 相序、角度方向、零偏、极对数、采样极性 |
| 空载电流大 | 角度偏差、id/iq 分配、机械阻力、参数和采样偏置 |
| 速度上升后失控 | 电压饱和、角度延迟、母线不足、控制执行超时 |
| 电流波形出现尖峰 | 采样窗口、放大器饱和、开关干扰、真实过流 |
| 减速时过压 | 回馈能量路径、制动设计、减速度限制 |

不要用“把 PI 调小一点”覆盖所有问题。先确认测量和角度正确，再讨论环路参数。

## 11. 自测

1. 为什么速度 PI 不直接输出 PWM？——速度通常通过转矩改变，iq 是更直接的转矩控制量，内部电流环负责克服电气动态和扰动。
2. 4 极电机的极对数是多少？——2，不是 4。
3. id=0 是否代表没有定子电流？——不是，iq 可以非零并产生转矩。
4. 为什么 ADC 平均值看似正确，电流环仍可能振荡？——瞬时采样时刻、延迟和噪声会影响闭环，仅检查平均值不足。
